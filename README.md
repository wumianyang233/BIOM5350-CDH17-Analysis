# CDH17 Expression and Tissue Selectivity in Colorectal Cancer

BIOM5350 Fall 2026 final project. The project asks how CDH17 RNA expression differs among colorectal tumors, normal colorectal samples, and other normal human tissues.

## Data source and expression scale

The analysis uses the UCSC Xena uniformly processed TCGA + GTEx Toil collection:

- Expression dataset: [`TcgaTargetGtex_rsem_gene_tpm`](https://toil.xenahubs.net/)
- Sample annotations: [`TcgaTargetGTEX_phenotype.txt`](https://toil.xenahubs.net/)
- Gene feature: `ENSG00000079112.9` (CDH17; Ensembl ID with the version suffix used by the matrix)
- Source expression scale: `log2(TPM + 0.001)`

The saved expression values remain on Xena's reported transformed scale. They are not converted to `log2(TPM + 1)`. The offset means that zero TPM corresponds to about `-9.9658` on this scale; values close to that bound may indicate expression at or near zero in the source quantification. The value is an RNA-seq measure and does not directly measure protein abundance.

The targeted acquisition requests one gene and selected phenotype annotations through Xena's data API; it does not download the multi-gigabyte expression matrix. `data/cdh17_expression_annotated.csv` contains 7,860 selected sample rows and is retained as the compact input needed to rerun the local EDA and statistics without making a network request. The larger all-sample intermediate is regenerated by the acquisition script and excluded from the proposed repository.

## Python environment

The workflow was checked with Python 3.14.4. Direct analysis and notebook-execution dependencies are pinned in `requirements.txt` (including `ipykernel` and `nbconvert` for executing the notebook). Create an environment and install them with:

```bash
python3 -m venv .venv
source .venv/bin/activate        # Windows PowerShell: .venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
python -m pip install -r requirements.txt
```

## Reproduce the workflow

Run these commands from the project root, in order:

```bash
python scripts/01_download_cdh17.py
jupyter nbconvert --to notebook --execute --inplace notebooks/02_CDH17_EDA.ipynb
python scripts/03_statistical_analysis.py
```

The first command makes targeted public Xena API requests and regenerates the annotated and raw sample tables, provenance, and acquisition QC outputs. The notebook reads the annotated CSV and regenerates `results/eda_summary.csv` and Figures A-C. The statistical script reads the same annotated CSV and regenerates the statistical summary, notes, and Figure D. The notebook can also be opened interactively; it locates the project root from the current directory and its parents, or from `CDH17_PROJECT_ROOT` if set. See [REPRODUCIBILITY.md](REPRODUCIBILITY.md) for the complete order and generated-file details.

## Statistical comparison summary

All tests are two-sided, unpaired Mann–Whitney U tests. Median differences are group 1 minus group 2 on `log2(TPM + 0.001)`. Rank-biserial correlation is oriented so a positive value means group 1 tends to have higher ranks. Holm adjustment covers the two primary TCGA tests only; the GTEx test is exploratory and unadjusted.

| Role | Comparison (group 1 vs group 2) | n | Medians | Median difference | Rank-biserial | p-value | Holm-adjusted p |
|---|---|---:|---:|---:|---:|---:|---:|
| Primary | TCGA colon primary tumor vs solid-tissue normal | 288 vs 41 | 7.4535 vs 8.2430 | -0.7895 | -0.5812 | 1.73e-09 | 3.47e-09 |
| Primary | TCGA rectum primary tumor vs solid-tissue normal | 92 vs 10 | 7.6750 vs 7.9195 | -0.2445 | -0.2293 | 0.2374 | 0.2374 |
| Exploratory | GTEx sigmoid vs transverse colon normal | 141 vs 167 | -1.0560 vs 6.9080 | -7.9640 | -0.7317 | 1.89e-28 | Not adjusted |

The rectum comparison is not statistically significant; this is not evidence of equivalence, particularly given the small normal group. See `results/statistical_analysis_notes.md` for method details and interpretation limits.

## Limitations

- TCGA and GTEx were processed through the same Toil pipeline, but they remain distinct cohorts with different collection, handling, and sampling procedures. No batch correction was applied; cross-source comparisons are exploratory.
- TCGA normal samples are treated as unpaired samples; patient matching is not assumed by the analysis.
- The rectum solid-tissue-normal group is small (`n=10`), limiting precision.
- The dataset is an older Toil release. Re-running acquisition may reflect changes in public Xena endpoints or annotations; the retrieval date and source metadata are recorded in `data/data_provenance.md`.
- RNA expression does not establish CDH17 protein abundance, ADC efficacy, or clinical safety.
